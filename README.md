# STOCKPRO 1.0

Sistema comercial de inventario multitienda en desarrollo. Esta rama contiene únicamente la **Etapa 1: estructura y diseño principal**. La interfaz actual es una maqueta responsive con información inventada para diseño; no representa ventas ni existencias reales y todavía no se conecta con Supabase.

## Ejecutar localmente

Abrí `index.html` en un navegador moderno. Para probarlo con un servidor local: `python3 -m http.server 8000` y visitá `http://localhost:8000`.

## Hoja de seguimiento

Consultar [SEGUIMIENTO.md](SEGUIMIENTO.md). Cada etapa se completa y prueba antes de iniciar la siguiente.

## Seguridad

No hay credenciales en el repositorio. Las tablas, autenticación y políticas RLS se diseñarán antes de habilitar datos reales. No desplegar ni usar para ventas reales hasta terminar las pruebas de seguridad y operación.
